### 7.2 Prepare the USB Storage Device

For the standard PS3 firmware update workflow:

1. Prepare a compatible USB storage device.
2. Format the storage device using FAT32.
3. Create a directory named `PS3`.
4. Inside it, create a directory named `UPDATE`.
5. Place the compatible firmware PUP file inside the UPDATE directory.
6. Use the standard firmware filename:

   `PS3UPDAT.PUP`

The expected directory structure is:

    USB:/
    └── PS3/
        └── UPDATE/
            └── PS3UPDAT.PUP
